# Aegis Web

React frontend for the Aegis Security Platform (Vite + TypeScript + Tailwind).

```bash
npm install     # install dependencies
npm run dev     # dev server on :5173, proxies /api to the Aegis server on http://localhost:8080
npm run build   # type-check + production build into dist/
```

Demo login: `admin@aegis.local` / `aegis-demo-admin-2026`

Keyboard shortcuts: `/` focus search · `Cmd/Ctrl+K` command palette · `g` then `a/s/v/e` to jump to Assets / Scans / Vulnerabilities / Events.
